# 文档索引

## 目录约定

| 目录 | 放什么 | 判断标准 |
| --- | --- | --- |
| `参考/` | 客观事实的查询手册 | 读者是来「查」的，内容不带主观决策 |
| `指南/` | 面向操作者的做法说明 | 读者是来「做」的 |
| `设计/` | 实现方案与取舍理由 | 读者是来「理解为什么」的 |
| `归档/` | 已失效但有追溯价值的文档 | 内容不再指导当前工作 |
| `抓包/` | 结构化抓包记录与外部素材 | 以实测请求/响应为核心的证据文档 |

## 文档头

每篇文档以 YAML front matter 开头，至少包含 `类型`、`状态`、`更新日期`：

```yaml
---
类型: 参考 | 指南 | 设计 | 归档 | 索引
状态: 有效 | 已过期
更新日期: YYYY-MM-DD
---
```

按需追加 `适用版本`、`数据来源`、`归档日期` 等字段。

## 维护约定

- 新增文档时按上表选目录，并加文档头。
- 术语以[术语表](参考/术语表.md)为准；新增概念先补术语表再写正文。
- 文档失效时移入 `归档/`，文件名加时间前缀（如 `2026-07-`），并把状态改为 `已过期`。
- 归档文档中仍有效的行动项应提取到 `指南/待办事项.md`，不要留在归档里。
- 新增抓包记录时遵循[抓包记录索引](抓包/README.md)中的格式：front matter 写明抓取元数据，响应只保留代表性节选，凭证必须脱敏。
