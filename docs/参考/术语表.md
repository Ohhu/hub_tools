# 术语表

统一本项目文档与代码中的用词，避免同一概念出现多种叫法。

## 平台与页面

| 标准用词 | 含义 | 不要使用 |
| --- | --- | --- |
| **Hub** | `hub.linux.do` 站点整体 | LinuxDo Hub、AxonHub（仅在说明后端实现时可提及） |
| **资源市场** | `/marketplace` 页面整体，含三个 Tab | Marketplace、市场页 |
| **模型广场** | 资源市场的「模型广场」Tab | 模型列表、Model Hub |
| **候选搜索** | 资源市场的「候选搜索」Tab | 候选列表 |
| **渠道广场** | 资源市场的「渠道广场」Tab | Channel Hub、渠道列表、渠道市场 |
| **模型详情页** | `/marketplace/models/:modelID` | 模型页、provider 页 |
| **密钥页** | `/project/api-keys` | API Key 页、密钥管理页 |

## 数据概念

| 标准用词 | 含义 | 不要使用 |
| --- | --- | --- |
| **渠道** | `Channel`，模型的提供方 | 供应商、provider（`MarketplaceProvider` 类型名除外） |
| **模型** | `modelID` 标识的模型 | 模型 ID（除非确指字段） |
| **价格行** | `ChannelModelPrice`，某渠道对某模型的定价记录 | 价格记录、定价项 |
| **价格项** | `ModelPriceItem`，价格行内按 `itemCode` 区分的条目 | 计费项 |
| **倍率** | `multiplier`，展示用换算系数，**不等于最终价格** | 价格系数 |
| **隐式免费** | 模型在渠道下不存在显式价格行，按免费处理 | 默认免费、无价免费 |
| **配置** | `APIKeyProfile`，密钥的渠道/模型绑定方案 | profile、档案、配置文件 |

## 脚本自身

| 标准用词 | 含义 | 不要使用 |
| --- | --- | --- |
| **脚本** | 本项目产出的油猴脚本 | 插件、扩展 |
| **产物** | 根目录 `LinuxDo Hub Tool.user.js` | 打包文件、bundle |
| **源码片段** | `src/` 下参与拼接的文件 | 模块（当前无模块系统） |

## 书写约定

- 引用页面按钮、Tab 等界面文字时用直角引号：「免费」。
- 引用代码标识符、字段名、路径时用反引号：`priceSummary.allFree`。
- 接口路径写完整形式：`GET /admin/marketplace/channels`。
- GraphQL 操作名保持原始大小写：`MarketplaceModel`、`GetApiKeys`。
