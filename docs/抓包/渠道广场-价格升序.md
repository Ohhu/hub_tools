# 渠道广场：价格升序列表

渠道广场按倍率升序浏览时的请求组合。凭证已脱敏。

## 请求 1：渠道列表（REST）

```text
GET /admin/marketplace/channels?page=1&first=20&tag=all&sort=multiplier_asc
authorization: Bearer <token>
referer: https://hub.linux.do/marketplace
```

## 请求 2：渠道探测数据（GraphQL）

页面拿到列表后，批量拉当前页渠道的探测曲线：

```graphql
query GetChannelProbeData($input: GetChannelProbeDataInput!) {
  channelProbeData(input: $input) {
    channelID
    points {
      timestamp
      totalRequestCount
      successRequestCount
      avgTokensPerSecond
      avgTimeToFirstTokenMs
    }
  }
}
```

```json
{ "input": { "channelIDs": ["gid://axonhub/Channel/2223", "gid://axonhub/Channel/2235", "……共 20 个"] } }
```

该请求带 `cache-control: no-cache` / `pragma: no-cache` 头。

## 要点

- `sort=multiplier_asc` 时免费渠道（`priceSummary.allFree: true`）排在前面，是脚本免费筛选翻页时选用该排序的依据。
- `budgetAmount` 顶层字段只在渠道设置过预算时出现（对照 `budgetStats.hasBudget`）。
- 探测数据按渠道 GID 批量查询，与列表分页同步。
