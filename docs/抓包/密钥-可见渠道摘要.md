# 可见渠道摘要查询（GetVisibleChannelSummarys）

密钥页编辑弹窗加载可绑定渠道列表的请求。凭证已脱敏。

## 请求

`POST /admin/graphql`，operationName `GetVisibleChannelSummarys`：

```graphql
query GetVisibleChannelSummarys($first: Int, $after: Cursor, $orderBy: ChannelOrder, $where: ChannelWhereInput) {
  channels(first: $first, after: $after, orderBy: $orderBy, where: $where) {
    edges {
      node {
        id name type status orderingWeight tags remark
        allModelEntries { requestModel actualModel source }
      }
      cursor
    }
    pageInfo { hasNextPage endCursor }
    totalCount
  }
}
```

```json
{
  "first": 200,
  "after": "gaFpzRnx",
  "where": { "statusIn": ["enabled", "disabled"] },
  "orderBy": { "field": "ORDERING_WEIGHT", "direction": "DESC" }
}
```

## 要点

- 每页 `first: 200`，游标翻页直到 `hasNextPage: false`；抓取时全量约 1722 个渠道。
- `allModelEntries` 的 `source` 标记模型来源（`direct` 等），`requestModel` / `actualModel` 支持模型映射。
- 按 `ORDERING_WEIGHT DESC` 排序，与弹窗展示顺序一致。
