# 密钥创建流程

在密钥页点击「创建 API 密钥」后的完整请求序列。凭证已脱敏（`authorization`、`cookie` 置为占位符）。

## 请求序列

按时间顺序共 4 步，均为 `POST /admin/graphql`，公共请求头：

```text
content-type: application/json
authorization: Bearer <token>            # 已脱敏
x-project-id: gid://axonhub/Project/1
referer: https://hub.linux.do/project/api-keys
```

| 步骤 | operationName | 作用 |
| --- | --- | --- |
| 1 | `CreateAPIKey` | 创建密钥 |
| 2 | `GetApiKeys` | 刷新列表 |
| 3 | `UpdateAPIKeyProfiles` | 为新密钥绑定渠道 |
| 4 | `Me` | 刷新用户上下文（无 `x-project-id` 头） |

## 步骤 1：CreateAPIKey

请求：

```graphql
mutation CreateAPIKey($input: CreateAPIKeyInput!) {
  createAPIKey(input: $input) {
    id createdAt updatedAt
    user { id firstName lastName }
    key name type status scopes
  }
}
```

```json
{ "input": { "name": "测试2", "type": "user", "projectID": "gid://axonhub/Project/1" } }
```

响应：

```json
{
  "data": {
    "createAPIKey": {
      "id": "gid://axonhub/APIKey/20701",
      "createdAt": "2026-05-08T07:40:52.790948506Z",
      "updatedAt": "2026-05-08T07:40:52.790948676Z",
      "user": { "id": "gid://axonhub/User/570", "firstName": "Merit", "lastName": "" },
      "key": "ah-REDACTED",
      "name": "测试2",
      "type": "user",
      "status": "enabled",
      "scopes": ["read_channels", "write_requests"]
    }
  }
}
```

要点：响应直接返回完整 `key`（仅此一次可见），`scopes` 默认 `read_channels` + `write_requests`。

## 步骤 3：UpdateAPIKeyProfiles

请求：

```graphql
mutation UpdateAPIKeyProfiles($id: ID!, $input: UpdateAPIKeyProfilesInput!) {
  updateAPIKeyProfiles(id: $id, input: $input) {
    id name status
    profiles {
      activeProfile
      profiles {
        name
        modelMappings { from to }
        channelIDs channelTags channelTagsMatchMode modelIDs
        loadBalanceStrategy channelBindingMode
        dynamicChannelStrategy {
          mode maxChannels minChannels maxPriceMultiplier maxLatencyMs
          minSuccessRate onlyOfficial includeTags excludeTags
          excludeChannelIDs fallbackChannelIDs
        }
        quota {
          requests totalTokens cost
          period { type pastDuration { value unit } calendarDuration { unit } }
        }
      }
    }
  }
}
```

```json
{
  "id": "gid://axonhub/APIKey/20555",
  "input": {
    "activeProfile": "default",
    "profiles": [{
      "name": "default",
      "modelMappings": [],
      "channelIDs": [5638],
      "channelTags": [],
      "channelTagsMatchMode": "any",
      "modelIDs": [],
      "channelBindingMode": "manual",
      "dynamicChannelStrategy": null
    }]
  }
}
```

要点：`channelIDs` 用**数字 ID**（`5638`），不是 GID。
