# 密钥更新流程

在密钥页编辑密钥（改名、重新绑定渠道）的请求序列。凭证已脱敏。

## 请求序列

均为 `POST /admin/graphql`，公共请求头同[密钥创建流程](密钥-创建.md)。

| 步骤 | operationName | 作用 |
| --- | --- | --- |
| 1 | `UpdateAPIKey` | 更新名称等基本信息 |
| 2 | `GetApiKeys` | 刷新列表 |
| 3 | `GetApiKey` | 拉取单个密钥详情（含 profiles） |
| 4 | `UpdateAPIKeyProfiles` | 保存渠道绑定 |

## 步骤 1：UpdateAPIKey

```graphql
mutation UpdateAPIKey($id: ID!, $input: UpdateAPIKeyInput!) {
  updateAPIKey(id: $id, input: $input) {
    id createdAt updatedAt
    user { id firstName lastName }
    key name type status scopes
  }
}
```

```json
{ "id": "gid://axonhub/APIKey/20555", "input": { "name": "wong 0.05x" } }
```

另一次抓取（2026-05-10）中页面请求了扩展的 user 字段（`email` / `avatar` / `linuxdoUserID` / `linuxdoUsername` / `linuxdoProfile {...}`），响应结构见[密钥列表查询](密钥-列表查询.md)的 user 节选——说明前端不同版本对同一 mutation 的选择集会变化，脚本不应假设固定选择集。

## 步骤 3：GetApiKey（通过 node 接口）

```graphql
query GetApiKey($id: ID!) {
  node(id: $id) {
    ... on APIKey {
      id createdAt updatedAt
      user { id firstName lastName }
      key name type status scopes
      profiles {
        activeProfile
        profiles {
          name
          modelMappings { from to }
          channelIDs channelTags channelTagsMatchMode modelIDs
          loadBalanceStrategy channelBindingMode
          dynamicChannelStrategy {
            mode maxChannels minChannels maxPriceMultiplier maxLatencyMs
            minSuccessRate onlyOfficial includeTags excludeTags
            excludeChannelIDs fallbackChannelIDs
          }
          quota {
            requests totalTokens cost
            period { type pastDuration { value unit } calendarDuration { unit } }
          }
        }
      }
    }
  }
}
```

```json
{ "id": "gid://axonhub/APIKey/20555" }
```

## 步骤 4：UpdateAPIKeyProfiles

与[密钥创建流程](密钥-创建.md)步骤 3 相同，但本次抓取的 input 里显式携带了 `loadBalanceStrategy: null` 和 `quota: null`：

```json
{
  "id": "gid://axonhub/APIKey/20555",
  "input": {
    "activeProfile": "default",
    "profiles": [{
      "name": "default",
      "modelMappings": [],
      "channelIDs": [5638],
      "channelTags": [],
      "channelTagsMatchMode": "any",
      "modelIDs": [],
      "loadBalanceStrategy": null,
      "channelBindingMode": "manual",
      "dynamicChannelStrategy": null,
      "quota": null
    }]
  }
}
```

## 要点

- 单密钥详情走通用 `node(id:)` + inline fragment，不是独立 query。
- `UpdateAPIKeyProfiles` 是全量覆盖语义：input 中省略/置 null 的字段即清空。
