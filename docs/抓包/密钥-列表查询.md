# 密钥列表查询（GetApiKeys）

密钥页加载列表时的请求。凭证已脱敏。

## 请求

`POST /admin/graphql`，operationName `GetApiKeys`：

```graphql
query GetApiKeys($first: Int, $after: Cursor, $orderBy: APIKeyOrder, $where: APIKeyWhereInput) {
  apiKeys(first: $first, after: $after, orderBy: $orderBy, where: $where) {
    edges {
      node {
        id createdAt updatedAt
        user {
          id firstName lastName email avatar
          linuxdoUserID linuxdoUsername
          linuxdoProfile {
            id username name avatarTemplate avatarUrl
            active trustLevel silenced externalIds updatedAt
          }
        }
        key name type status scopes
      }
      cursor
    }
    pageInfo { hasNextPage hasPreviousPage startCursor endCursor }
    totalCount
  }
}
```

```json
{
  "first": 20,
  "where": {
    "statusIn": ["enabled", "disabled"],
    "userID": "gid://axonhub/User/570",
    "typeNotIn": ["noauth"]
  },
  "orderBy": { "field": "CREATED_AT", "direction": "DESC" }
}
```

## 要点

- Relay 游标分页，`where` 支持 `statusIn` / `typeNotIn` / `userID` 组合过滤。
- 列表响应包含完整 `key` 字段（服务端不打码）。
- `typeNotIn: ["noauth"]` 用于排除免认证密钥。
