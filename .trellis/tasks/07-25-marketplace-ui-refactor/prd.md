# 适配渠道广场并优化项目结构

## Goal

适配 LinuxDo Hub 最新资源市场页面，重点修复模型详情提供商列表的筛选布局和 API 密钥操作入口；同时保持渠道广场兼容，并在不改变单文件 userscript 发布方式的前提下，将只有形式边界的源码整理为职责真实、易维护的模块。

## Requirements

- 渠道广场新增的“渠道 ID”“健康序列”和视图控件必须保持可见、可操作，脚本的免费筛选不得覆盖站点控件。
- 免费筛选必须成为筛选网格中的最后一个正式字段，并使用紧凑的胶囊式切换按钮和站点明暗主题变量。
- 站点原生“添加到已有密钥”按钮必须由脚本的增强按钮直接替换，每个模型 provider 或渠道项只保留一个 API 密钥操作入口。
- 继续兼容旧版“创建 API 密钥”以及英文按钮文本，避免站点灰度发布或语言切换导致功能失效。
- 替换后的按钮继续打开脚本现有增强对话框，保留追加、替换、新建、编辑渠道列表和排序等功能。
- 替换后的渠道按钮使用脚本统一维护的钥匙图标和轻量强调样式，不继承原生按钮的视觉 class。
- 模型详情 provider 和渠道项中的“真伪核验”操作入口由脚本移除，保留查看定价、更新 API 密钥和提交举报等其他操作。
- 删除没有运行时代码的纯注释占位模块；只有在真实代码迁入后才保留模块文件。
- 合并仅保存共享缓存变量的薄状态模块，并将只服务渠道缓存的比较辅助函数归入渠道模块。
- 将 marketplace、DOM、channels 和 API Keys 中已识别的大职责块迁移到对应功能模块，保持现有行为和零依赖拼接构建。
- 最终仍发布单个 `LinuxDo Hub Tool.user.js`，不引入 `@require`、动态 import 或第三方构建依赖。
- 不回退或覆盖工作区中已有的未提交修改。

## Acceptance Criteria

- [x] 价格筛选始终位于当前市场筛选网格末尾；窄屏按站点网格自然换行。
- [x] “免费”按钮不与健康序列、视图切换或其他控件重叠，明暗主题下样式一致。
- [x] 每个渠道项中不再同时出现“添加到已有密钥”和“更新 API 密钥”。
- [x] 每个渠道项只显示一个脚本自有样式的“更新 API 密钥”按钮，并且不再显示“真伪核验”。
- [x] 脚本能识别并替换中文旧/新文案及对应英文 API Key 操作文案。
- [x] 点击替换后的按钮可以打开脚本增强对话框，并携带正确的渠道 ID 和名称。
- [x] `src/` 中不再保留纯注释占位文件，构建清单只包含实际运行时代码。
- [x] 原有 API Key、请求页入口、市场价格过滤和模型价格逻辑的自动化测试继续通过。
- [x] 新增针对新版按钮识别、替换幂等性和筛选字段结构的回归测试。
- [x] 构建、同步校验、全量 Node 测试和语法检查全部通过。
- [x] 在已登录 Chrome 的模型详情 provider 列表完成筛选顺序、单一 API Key 入口、对话框和免费筛选验证，无脚本新增控制台错误。
- [x] 服务可用时补充渠道广场卡片/列表兼容性检查；服务端 520 不阻断模型详情页本身的验收。
